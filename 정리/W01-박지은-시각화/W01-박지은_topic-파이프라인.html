2. extract — 개념과 관계로 연결

→ 키를 누를 때마다 그래프가 한 단계씩 자라요: 개념 후보 → 같은 unit 안의 관계 → 중복·동의어 후보 → 문서↔코드 관계.

unit 안에서 함께 등장중복·동의어 후보 (자동 통합 안 함)supported_bycontradicted_by
Synonym Proposal게시자 본인 ≟ 대표 크리에이터
티켓 TICKET-17은 "대표 제외는 기존 게시자 본인 조건이 맡는다"라고 적어 둘을 같게 다루지만, 정책은 판에 따라 다른 용어를 써요. 애매한 별칭이라 자동으로 합치지 않고 사람의 승인을 기다려요.
Synonym Proposal직원: 이름 셋
관객 점수 정책은 {회원 권한 - 직원}, 용어집은 "기존 명칭, 현재는 {회원 소속 - 직원}", 코드는 members.role = STAFF(7). 대표 개념 후보는 용어집의 현재 이름이에요.
supported_by개정판 → collectEntryMetrics
"대표 크리에이터 및 해당 영상의 참여 확정 크리에이터 본인 … 기록은 모두 제외" ↔ excludeConfirmedMember 조건 3곳 (시청·좋아요·댓글)
contradicted_by기본 정책 · A 챌린지판 → 같은 코드
"게시자 본인 … 제외"만 적혀 있어, 참여자 반응까지 빼는 현재 코드와 충돌해요.
supported_by기본 정책 → MIN_WATCH_SECONDS
"시청률 점수 = (5초 이상 시청수 ÷ 재생수) × 2점" ↔ s.stay >= MIN_WATCH_SECONDS (= 5)
저장하는 것관계마다
종류 · 근거 인용 · 신뢰도 · 판단 상태. 검증 호출이 실패하거나 신뢰도가 낮으면 관계를 만들지 않아요.

3. verify — 6가지 축으로 판정

먼저 규칙(해시·anchor)으로 바뀐 범위만 고르고, 바뀐 것만 LLM으로 의미를 다시 검증해요.

Granularity (세분성)

개념이 될 만한 단위인가?

pass "본인 반응 제외"
drop "14:00~14:59" — 1시간 묶음의 예시일 뿐 개념이 아님

수십 KB짜리 정책 전체가 아니라 「기본 집계 제한」 섹션 하나가 unit이에요.

Faithfulness (충실성)

원문이 뒷받침하는가?

supported 개정판 → 코드
refuted 기본 정책 → 코드

NLI 방식: supported / refuted / not enough info

Staleness (낡음)

원문이 지금도 그렇게 말하는가?

anchor 있음?→예→span hash 변경 (a1b2c3d4)→faithfulness 재검증

코드는 11-04에 바뀌었는데 기본 정책은 10-22 그대로 → stale_risk

Canonicality (정규성)

다른 이름이 같은 대상인가?

proposal 게시자 본인 ≟ 대표 크리에이터
proposal 직원 이름 셋 → {회원 소속 - 직원}

애매하면 합치지 않고 사람 승인 대기.

Consistency (일관성)

출처끼리 양립하는가?

consistent 기본 정책 ↔ A 챌린지판
contradicts 기본 정책 ↔ 개정판
complementary 개정판 ↔ TICKET-17 (판정 시점을 덧붙임)

충돌을 발견해도 한쪽을 조용히 지우거나 승자를 정하지 않아요.

Coverage (포괄성)

빠진 것은?

gap 퇴사자 반응을 세는지

코드에는 ALUMNI = 8 // 점수 집계에 포함이 있지만, 관객 점수 정책 두 판 모두 퇴사자를 언급하지 않아요. 코드에만 있는 규칙이에요.

4. serve — 답이 아니라 믿을 수 있는 컨텍스트를 건넴

"Topic은 답을 만드는 시스템이 아니에요. 답을 만드는 데 사용되는 컨텍스트를 믿을 수 있게 만드는 시스템이에요."

💬 공모전 출품작에 참여 크리에이터가 누른 좋아요도 관객 점수에서 빠지나요?
partly_trusted

빠져요. 단, 그 영상의 참여 태그를 참여 확정한 경우에만이고, 확정 전에 누른 좋아요도 빠져요. 최종 평가가 저장된 뒤 확정·제거가 생겨도 다시 계산하지 않아요.

정리 — 검색만 했다면 기본 정책의 "게시자 본인만 제외"가 그럴듯한 답으로 나왔을 거예요. Topic은 그 문장이 낡았고, 코드와 충돌하며, 더 새로운 개정판과 결정 기록이 있다는 사실까지 함께 건네요.
