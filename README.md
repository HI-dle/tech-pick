- 현황판: [[스터디.base]] — 뷰 `선정` / `후보` / `정리` / `토론`

## 주간 루틴

| 언제 | 할 일 | 파일 |
| --- | --- | --- |
| 모임 전 | 각자 읽고 싶은 후보 추가 (누적, 지난 후보 재투표 가능) | `후보/` |
| 모임 | 투표로 1개 선정 → 선정된 후보에 `선정주차` · `선정일` · `토론일` 기입 | `후보/` |
| 한 주 동안 | 읽고 자유 양식으로 정리 | `정리/` |
| 다음 모임 | 정리 기반 토론 → 결론 · 나온 질문 기록 (선택) | `토론/` |

## 파일 작성법

`템플릿/`의 파일을 복사하거나 Obsidian 템플릿 폴더로 지정해 사용. **frontmatter의 `type`으로 현황판에 분류되므로 폴더가 아닌 `type`이 기준.**

### 후보 — `후보/<글 제목>.md`

파일명 = 제목. 필수는 `링크` · `추천자`, 나머지는 선택.

| 속성 | 예시 | 설명 |
| --- | --- | --- |
| `링크` | `https://...` | 메인 링크 하나 |
| `추천자` | `박지은` | |
| `생성일시` | `2026-10-29T21:30` | 템플릿이 자동 입력 |
| `종류` | `블로그` / `논문` / `영상` / `가이드` / `기타` | |
| `한줄이유` | | 왜 읽고 싶은지 |
| `관련링크` | `[https://a, https://b]` | 파생 링크 목록. 링크 간 맥락은 본문에 |
| `태그` | `[ai, ddd]` | |
| `선정주차` · `선정일` · `토론일` | `W01` · `2026-10-29` · `2026-11-05` | 선정 시에만 기입. 비어 있으면 `후보` 뷰, 채워지면 `선정` 뷰 |

- 링크의 `utm_source` 등 추적 파라미터는 제거
- 주차는 스터디 시작 기준 순번 `W01`, `W02` …

### 정리 — `정리/<주차>-<이름>.md`

본문은 자유 양식. frontmatter만 채움.

- `대상`: 선정된 후보 링크 `"[[LLM은 똑똑한데, 왜 우리 회사 일은 모를까]]"`
- `작성자`

주차 · 토론일은 `대상` 후보에서 자동으로 끌어와 `정리` 뷰에 표시.

### 토론 — `토론/<주차>.md`

- `주차` · `토론일` · `대상` · `참석`
- 본문: `## 결론`, `## 나온 질문`
